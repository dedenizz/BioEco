# BioEcosystem: Autonomous Multi-Agent Evolution Engine

BioEcosystem is an experimental artificial life and evolutionary simulation continuously engineered and maintained by an autonomous multi-agent development studio.

## Studio Philosophy & Work Division
The project is built on an hourly schedule using specialized roles that work calmly, one focused task at a time:
- The Challenger (Product Critic): Questions usability, engagement, and product depth.
- The Lead Planner: Maps out upcoming sessions without rushing.
- The Builders: System Agent (math/mechanics), Looks Agent (visual fluid fidelity), UI Agent (zero-emoji telemetry).
- QA & Bug Fix Agent: Profiles 60 FPS performance, hunts memory leaks, audits slop/emojis.
- Executive Director: Macro reviews to ensure the simulation develops into a deep, emergent life ecosystem.
