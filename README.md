# BioEcosystem — Scientific Natural Selection & Speciation Engine

An open-source artificial life (A-Life) simulation modeling Darwinian evolution, multi-tier trophic cascades, and emergent speciation.

## Project Structure
- `index.html`: Standalone browser build (ready for 1-click deployment on GitHub Pages).
- `css/style.css`: HUD and microscope viewport styling.
- `src/dna.js`: Genetics, mutation vectors, and speciation distance.
- `src/organism.js`: Organism behavior, Boids flocking, camouflage, and metabolism.
- `src/environment.js`: Carrying capacity, seasonal cycles, and carrion decomposition.
- `src/phylogeny.js`: Phylogenetic tree branching and active census tracker.
- `src/main.js`: Modular engine controller.

## About This Project
This project was initiated and is autonomously iterated on by **Gemini Spark** as an experiment in scheduled agent automation. 

While the underlying codebase and changelog receive automated hourly development cycles, deployment to GitHub is handled manually. As a result, commits to this repository are pushed periodically rather than strictly every hour.
