# BioEcosystem: Autonomous Multi-Agent Evolution Engine

BioEcosystem is an experimental artificial life and evolutionary simulation continuously engineered and maintained by an autonomous multi-agent development architecture.

## Automated Engineering Architecture

This software is developed through an automated, scheduled lifecycle powered by specialized agent roles that rotate through focused development sessions. Rather than uncoordinated code generation, development operates under strict software engineering principles: modular separation, anti-slop visual restraint, and persistent phylogenetic modeling.

### Specialized Agent Roles

- **Overview & Planning Agent (Director):** Evaluates macro-level project trajectory, manages long-term roadmaps, and determines the focus of upcoming operational cycles.
- **System Agent (Core Engine):** Architectures mathematical models for genetic inheritance, Euclidean speciation distance metrics, trophic cascades, and thermodynamic metabolic burn rates.
- **Looks Agent (Aesthetics & Motion):** Refines visual fidelity, focusing on fluid microscopic motion, cellular membrane deformations, and organic trailing particle dynamics.
- **UI Agent (Telemetry & Interfaces):** Designs restrained, zero-emoji scientific telemetry heads-up displays (HUD), monospace figures, and taxonomic census inspector panels.
- **Bug Fix & QA Agent (Auditor):** Profiles runtime performance (sustaining stable 60 FPS), investigates memory leaks, eliminates redundant logic, and enforces strict zero-emoji standards.

### Cyclic Session Model

Development follows a structured 4-phase rotating cycle:

1. **Strategic Planning & Roadmapping:** Reviews recent ecological stability and drafts feature specifications for upcoming milestones.
2. **System Engineering:** Implements foundational biological and physical algorithms in modular ES scripts.
3. **Aesthetic & Interface Refinement:** Tunes rendering pipelines, color theory, and data presentation.
4. **Quality Assurance & Verification:** Audits code cleanliness, verifies file integrity, and packages standalone distribution builds.

## Project Structure

- `index.html`: Standalone simulation build executable directly in modern web browsers.
- `src/`: Modular ES source modules (genetics, organism behaviors, environment models).
- `css/`: Laboratory telemetry and viewport stylesheet.
- `CHANGELOG.md`: Detailed release notes and biological rationale recorded after each operational cycle.
- `docs/`: Strategic roadmaps, architecture specifications, and session schedules.
