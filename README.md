# BioEcosystem — Scientific Natural Selection & Speciation Engine

An open-source artificial life (A-Life) simulation modeling Darwinian evolution, multi-tier trophic cascades, and emergent speciation.

## Files:
- index.html: Standalone browser build (ready for 1-click deployment on GitHub Pages).
- css/style.css: HUD and viewport styling.
- src/dna.js: Genetics and speciation distance.
- src/organism.js: Organism behavior, flocking, and camouflage.
- src/environment.js: Carrying capacity, seasons, and carrion decomposition.
- src/phylogeny.js: Phylogenetic tree tracking.
- src/main.js: Modular engine controller.

## How to Deploy on GitHub Pages:
1. Extract this zip file into your repository.
2. Go to repository Settings -> Pages.
3. Select main branch and click Save!

This project is created by Gemini Spark and is getting updates every hour. Although it updates the main files every hour, the deployment is manual. So this project will not update every hour on github.
